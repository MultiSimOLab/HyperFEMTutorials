HyperFEM tutorials

Tutorials of HyperFEM.jl, a library of the Gridap ecosystem for the finite-element simulation of multiphysics problems with hyperelastic materials: thermo-, electro- and magneto-mechanics at finite strains, contact, fluids, transient problems and solvers for large systems.

Every tutorial is a self-contained Julia script in the src/ folder of the repository. Its page explains the problem, the equations and every step of the code, and links to a Jupyter notebook generated from the same script. Each script ends with quantitative checks of its result (exact solutions, published benchmarks, conservation laws), which are also the test suite of the repository.

Getting started

git clone https://github.com/MultiSimOLab/HyperFEMTutorials.git
cd HyperFEMTutorials
julia --project=. -e 'using Pkg; Pkg.instantiate()'
julia -t 4 --project=. src/E02_Hyperelastic_stretch.jl

The tutorials need Julia 1.12 or later and use HyperFEM 0.3, HyperFEMKernels 0.2.6 and Gridap 0.20.8. See Running and testing for reduced cases, notebooks and tests.
