# Meshes used by the tutorials

| File | Used by | Description and origin |
|---|---|---|
| `test_static_EM.msh` | E04, E05 | Dielectric elastomer block with an embedded mid-surface electrode; 266 hexahedra; physical tags `fixedup`, `midsuf`, `topsuf`. From HyperFEM's test models (the electro-mechanics example of its README). |
| `Piston_1.msh`, `Piston_0.5.msh` | E06 | Piston pressed into a block through a third medium (2D); element sizes 1 and 0.5. From HyperFEM's third-medium contact test (Faltus, Amato and Horák 2026, Sec. 3.3). |
| `Short_magnet.msh` | E08, E09 | 2D hard-magnetic hMRE beam with the surrounding vacuum; surfaces `Beam`, `Magnet`, `Vacuum`, `vacuumb`; boundaries `Interface`, `Fixed_*`, `phibot`, `phitop`. From the MultiSimO Lab ultra-soft magnet study (`Adv_Mater_Ultra_Soft_Magnet`). |
| `turek2d.msh` | E10, E11 | DFG benchmark channel with a cylinder (Schäfer & Turek 1996), 7 402 triangles, h = 0.02. Generated by `turek.jl` (Gmsh). |
| `aorta_fluido_h1p5_3p0.msh` | E12 | Patient-specific aorta lumen (ascending aorta, arch with three branches, descending aorta); 33 643 linear tetrahedra, 10 455 nodes, Gmsh 4.1; physical tags `inlet`, `wall`, `outlet`, `B1`, `B2`, `B3`, `fluid`; units mm. Coarse mesh of the MultiSimO Lab hemodynamics project, built from a segmentation (no generator script); the same file as HyperFEMKernels.jl `examples/aorta_cfd/`. |

Generators: `turek.jl` (run with `julia --project=. data/models/turek.jl` from the repository root).
The other tutorials build their meshes in the script (`CartesianDiscreteModel`).

Reference data (`data/reference/`): `horak2026_piston_f_vs_uy.json`, force–displacement curve of the piston
(Faltus, Amato and Horák 2026) used by the checks of E06.
